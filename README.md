# InAmigos Foundation: AI Internship Tasks

Four AI-for-social-impact tasks completed during my AI internship at **InAmigos Foundation** (August 2026). Each task is documented in a written report, typeset in Overleaf (LaTeX).

The tasks cover AI tool evaluation, prompt engineering, AI-assisted content creation, and practical AI ideas for NGOs.

## Tasks

| # | Task | Report | Summary |
|---|------|--------|---------|
| 1 | **AI Tools Discovery** | [`reports/task1_ai_tools_discovery.pdf`](reports/task1_ai_tools_discovery.pdf) | Explored five AI tools from different categories: Overleaf AI (academic writing), Grammarly AI (proofreading), Google Meet with Gemini (communication), Notion AI (productivity) and Claude (assistant). For each tool: a definition, key characteristics, its AI features, practical uses and references. |
| 2 | **The RISE Prompt Master** | [`reports/task2_rise_prompt_master.pdf`](reports/task2_rise_prompt_master.pdf) | Designed a structured **RISE** prompt (Role, Input, Steps, Expectation) for an NGO writing a formal proposal to a Gram Panchayat about repairing village roads and drainage. Compared a basic prompt with the RISE prompt on specificity, tone, structure, credibility, call to action and control over output. |
| 3 | **#CyberKanya campaign** | [`reports/task3_cyberkanya_campaign.pdf`](reports/task3_cyberkanya_campaign.pdf) | Created a financial-literacy awareness campaign for girls ("Screen Se Financial Freedom Tak"). Gemini was used for the concept, Imagine.art for the illustration, Claude for the caption, and Overleaf for the poster layout. |
| 4 | **AI for Social Impact** | [`reports/task4_ai_for_social_impact.pdf`](reports/task4_ai_for_social_impact.pdf) | Proposed five practical AI ideas for NGOs: a smart task-reminder system (volunteer management), AI-generated practice worksheets (education), an automated social media content calendar (awareness), a ration and resource allocation planner (community support), and a photo-based health-change detector for shelter animals (animal welfare). |

## Skills demonstrated

- Prompt engineering with a structured framework (RISE)
- Evaluating and comparing AI tools
- AI-assisted content creation (concept, image, copy)
- Framing real NGO problems as AI use cases
- Technical writing and document typesetting in LaTeX
